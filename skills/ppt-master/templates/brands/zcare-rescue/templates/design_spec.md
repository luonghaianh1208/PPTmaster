# 子鹊救援 Z-CARE Brand Specification

> Identity-only preset. No SVG page roster — pages are composed freely under these constraints.

## I. Brand Overview

| Property | Value |
|---|---|
| Brand Name | 子鹊救援 Z-CARE（子鹊应急救援队 · Z-CARE EMERGENCY RESCUE TEAM） |
| Use Cases | 队内技术分享与训练课件、作业规范讲解、对外科普与协作交流材料 |
| Tone | 冷静、精确、可复核；讲代价不讲豪情 |
| Sources | 队伍自有标识文件（9 件锁定形式，随本工作区打包于 `../images/`）；配色由标识与队伍实拍装备取样，非官方色卡 |

## II. Color Scheme

| Role | HEX | Provenance |
|---|---|---|
| primary | #081830 | approx |
| secondary | #8890A0 | approx |
| accent | #D8F04A | approx |
| secondary_accent | #E85D2B | approx |
| text_on_primary | #FFFFFF | approx |

深藏青取自主徽章底与鹊鸟符号，浅蓝灰取自徽章嘉禾与绶带；荧光黄绿取自队伍 PFD 与头盔反光条，橙红取自干式救援服。四者均为取样近似值，不是官方色卡——遇到官方色号时以官方值替换。深藏青作为大面积底色时可按材料需要微调明度（例如投影场景放亮到 `#0E1B2E`），识别色本身不变。

## III. Typography

| Role | Family | Weight |
|---|---|---|
| title | Microsoft YaHei | bold |
| body | Microsoft YaHei | regular |
| display | Arial Black | bold |
| data | Arial | regular |

非官方指定字体，是队伍材料的使用约定：中文走 Microsoft YaHei，拉丁与数字走 Arial；章节数字、级别标记与冲击数字用 Arial Black 取得重量对比；表格与图表数值用 Arial 保证数字等宽等高。西文与中文同栈时中文永远走 EA 字族。

## IV. Logo

- File: `../images/zcare_badge.png`
- Usage: cover-only

默认呈现实体是主徽章。其余锁定形式按场景选用：深底横版用 `zcare_lockup_horizontal_white.png`，浅底横版用 `zcare_lockup_horizontal.png`，竖向版面用 `zcare_lockup_vertical.png`，水域专项材料可用 `zcare_water_badge.png`，章节页与衬底装饰用 `zcare_mark_white.png` / `zcare_mark_navy.png`（低透明度），页脚与角标用 `zcare_wordmark_white.png`。徽章与字标不拉伸、不改色、不加描边或阴影，最小净空不小于徽章高度的四分之一。

## V. Voice & Tone

- Formality: neutral
- Person: informal-you
- Emoji: forbidden
- Abbreviations: spell-out-first

面向队员讲机制时用「你」，把判断落到听者身上；不使用口号式表述，不渲染牺牲。PFD、SRT/DRT、XF/T 这类缩写与标准号首次出现时展开全称。

## VI. Icon Style

- Preference: linear

细线描边图标，与技术线稿图解同族；投影与打印场景下线宽不低于 2。
